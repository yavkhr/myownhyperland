# hyprkit

Мой конфиг Hyprland на Fedora. Ставится через меню в терминале: запускаешь
`./hyprkit`, оно проверяет, что уже стоит, и раскладывает выбранное.

```
git clone https://github.com/yavkhr/fedora-hyperland-by-yavkhr.git
cd fedora-hyperland-by-yavkhr
./hyprkit
```

Выглядит так:

```
hyprkit 0.1                        made by yavkhr

  Система   : Fedora Linux 44 (dnf)
  Hyprland  : 0.56.2
  Сессия    : запущена

  1) Waybar — установлено
  2) Lock screen — не установлено
  3) Бинды — установлено
  4) Обои — не установлено
  5) Меню hyprwat — не установлено
  6) Шрифты — не установлено

  Номера через запятую, a — всё, q — выход
  >
```

Пункты, которые уже стоят, помечены сразу, так что видно, что осталось.

## Что есть

- Waybar: раскладка, VPN и Wi-Fi, звук, температуры CPU и GPU, память, кнопки питания
- hyprlock: мой локскрин с аватаркой, блюром и полем ввода пароля
- Бинды: `hyprland.lua` со всеми хоткеями, плюс лончеры для viber, telegram, obsidian
- Обои через hyprpaper
- hyprwat: меню Wi-Fi, выбор языка и power-меню
- Шрифты: Nerd Fonts Symbols и JetBrainsMono

Компоненты можно ставить по одному, а можно всё сразу. Зависимости вроде
`waybar` или `hyprlock` скрипт проверяет сам и предлагает доставить.

Работает не только на Fedora: если в системе есть `dnf`, `pacman`, `apt` или
`zypper`, пакеты поедут через него. Если менеджер незнакомый, скрипт просто
скажет, что доставить руками.

## Что стоит знать

Бинды лежат в Lua-формате. Hyprland ниже 0.56 его не понимает, на таких
версиях ставится обычный `hyprland.conf` с теми же хоткеями.

`hyprwat` — готовый бинарь, собран под Linux x86_64. На другой архитектуре
его придётся собрать из исходников.

JetBrainsMono Nerd Font качается с GitHub, около 130 МБ. Без интернета
поставится только Symbols, остальное доставится пакетом.

Старые файлы при установке не удаляются, а уезжают в
`~/.hyprkit-backup-<дата>`. Вывод пакетных менеджеров пишется в
`~/.hyprkit.log`, на экран выводится только результат.

После установки:

```
hyprctl reload
pkill waybar; waybar &
```

Хоткеи: `Super+Return` — kitty, `Super+Space` — fuzzel, `Super+Q` — закрыть
окно, `Super+Shift+S` — скриншот, `Super+M` — заблокировать, `Super+F12` — выйти.

Скрипты `viber`, `telegram`, `obsidian` — обёртки под мои пути, их лучше
поправить под себя в `~/.local/bin`.

Полный бэкап системы (пакеты, `/etc`, настройки драйверов) лежит отдельно,
в приватном репозитории `myownfedora44`.
